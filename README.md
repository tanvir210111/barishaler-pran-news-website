# বরিশালের প্রাণ (Barishaler Pran) - অনলাইন সংবাদমাধ্যম

"সত্যের সঙ্গে, মানুষের পাশে" — বরিশালের প্রাণ (Barishaler Pran) একটি আধুনিক, দ্রুতগতির ও বস্তুনিষ্ঠ ডিজিটাল সংবাদ পোর্টাল।

## 🚀 প্রযুক্তি বিবরণী (Tech Stack)
- **Framework:** Next.js (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Typography:** SolaimanLipi, Noto Sans Bengali

## 💻 লোকাল ডেভেলপমেন্ট (Local Development)

```bash
# ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

ব্রাউজারে ওপেন করুন: [http://localhost:3000](http://localhost:3000)

## 📌 রুটসমূহ (Key Routes)
- **হোমপেজ:** `/`

- **জনপ্রিয় খবর:** `/popular`
- **আর্কাইভ:** `/archive`
- **ছবি গ্যালারি:** `/gallery`
- **ভিডিও সংবাদ:** `/videos`
- **বিজ্ঞাপন:** `/advertise`
- **আমাদের সম্পর্কে:** `/about`
- **যোগাযোগ:** `/contact`
- **অ্যাডমিন প্যানেল:** `/admin`
